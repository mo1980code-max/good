## 3) كيف تُجري التحقق (أمر واحد)

```bash
bash tools/verify.sh          # يشغّل pub get + analyze + test ويكتب تقريرًا
```

التقرير يُحفظ في `docs/verification-result.txt` ومحتواه:

```
flutter pub get
flutter analyze
flutter test
+ إحصاءات البنية (عدد ملفات Dart/الاختبارات/الأصوات/الصور وحجم assets)
```

ثم على جهاز حقيقي أو محاكي:

```bash
flutter run
```
